# Proyek Akhir MSML - Workflow CI

Repository ini digunakan untuk implementasi Continuous Integration (CI) serta automated modeling menggunakan MLflow melalui GitHub Actions.

## Tautan Docker Hub
https://hub.docker.com/r/jonathanlukasw/csgo-prediction-ci

## ✨ Struktur Repositori
- `.github/workflows/` : Konfigurasi otomatisasi GitHub Actions.
- `MLProject` & `conda.yaml` : Manifes tracking eksperimen MLflow.
- `modelling.py` : Skrip utama untuk pelatihan model.
